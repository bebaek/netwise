# Security Policy

Netwise processes sensitive financial-planning data. Please report security issues privately and do not include real financial records, credentials, session tokens, environment files, or database dumps in a report.

## Reporting a vulnerability

Use [GitHub's private security advisory form](https://github.com/bebaek/netwise/security/advisories/new) to report a suspected vulnerability. Do not open a public issue for an undisclosed security problem.

Include, when possible:

- The affected revision or version.
- The vulnerable component or endpoint.
- Reproduction steps using synthetic data.
- The expected and observed behavior.
- The likely impact and any suggested mitigation.

You should receive an initial acknowledgement within seven days. A remediation timeline will depend on severity and complexity. Please allow time for a fix before public disclosure.

## Supported versions

Until Netwise publishes versioned releases, only the latest revision of `main` receives security fixes.
